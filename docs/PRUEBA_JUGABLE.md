# Prueba breve del laboratorio

Estado: pendiente de realizar con una persona. Este documento no acredita una prueba.

## Objetivo para quien juega

Abre `builds/windows/Biotech.exe` con su PCK al lado. Consigue atender pedidos y mejorar la máquina usando las indicaciones del juego. Después cierra desde la pausa y vuelve a abrir para continuar.

Para comprobar la primera experiencia hace falta una partida nueva. El ejecutable comparte la partida de F5; no la reinicies si quieres continuar tu progreso. En otro equipo o cuenta de Windows se empieza de cero automáticamente.

## Qué observar

Dejar que la persona lo intente sin explicarle la secuencia. Si solicita ayuda, anotar dónde y ayudar; ese recorrido ya no acredita comprensión sin instrucciones verbales. No hace falta grabar ni instalar herramientas.

| Observación | Resultado real |
|---|---|
| Fecha y versión probada | Pendiente |
| ¿Descubre cómo moverse y usar los equipos? | Pendiente |
| Tiempo hasta entregar el primer pedido | Pendiente |
| ¿Entiende qué hacer mientras produce? | Pendiente |
| ¿Descubre y compra la mejora? | Pendiente |
| Tiempo total y pasos donde pide ayuda | Pendiente |
| ¿Al cerrar/reabrir reconoce su progreso? | Pendiente |
| ¿Hay texto cortado, parpadeo o personajes mal tapados? | Pendiente |

Al terminar, preguntar qué parte repetiría, qué le resultó tedioso y qué esperaba poder hacer. Registrar sus palabras y separar lo observado de nuestras propuestas.

## Elegir el próximo incremento

- Si no entiende una acción: corregir esa indicación o interacción y repetir ese paso.
- Si entiende el recorrido pero esperar resulta tedioso: concretar una tarea corta durante la producción antes de ampliar contenido.
- Si la gestión resulta interesante: evaluar un segundo encargo que comparta recursos, conforme a H5.

Estas son opciones para interpretar la prueba, no funcionalidades ya aprobadas ni implementadas. No dar H4 por cerrado solo con pruebas automáticas.
