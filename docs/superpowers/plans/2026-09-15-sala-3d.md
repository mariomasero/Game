# Primera sala 3D — Implementation Plan

> Ejecución incremental en esta sesión. Las decisiones rutinarias y reversibles están autorizadas por AGENTS.md y la petición de comenzar. Sin commits ni nuevas dependencias.

**Goal:** Arrancar una habitación 3D, recorrerla y abrir/cerrar el terminal.
**Architecture:** Escenas pequeñas para sala, jugador, terminal y UI. Composición local, sin autoloads.
**Tech Stack:** Godot 4.6.2, GDScript tipado, primitivas y sprites existentes.
**Spec:** `docs/decisions/002-sala-3d.md`; alcance H1.1–H1.4 de `DEVELOPMENT_PLAN.md`.

## Restricciones

Mundo 3D, personaje 2D, cámara de orientación fija, entradas existentes. Conservar fuentes y base 2D. Sin economía, compras, plugins ni commits. Primera muestra con 640×360 y escalado entero. Registrar limitaciones de las verificaciones.
